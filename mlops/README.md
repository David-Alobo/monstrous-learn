# MLOps for Chemists

Machine-learning models for chemistry that can be reproduced, deployed and monitored.

**Status:** Coming later

Training a model once is the easy part. This track covers what keeps models useful: reproducible training, experiment tracking, model registries, deployment, and watching for drift as new chemistry arrives. It builds on the data engineering track. The outline will be published here first.
