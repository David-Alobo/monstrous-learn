# Data Engineering for Chemistry

Chemical data you can trust: databases, pipelines, validation, scale and monitoring.

**Status:** January 2027

Three series that take chemical data from loose files to production pipelines: first the engineering itself, built by hand (Series 1), then the industry tools that run it at scale (Series 2), then the data side of automated and autonomous chemistry (Series 3).

## Series

1. [Data Engineering for Cheminformatics](series-1/): From SDF files to chemical data pipelines that scale to millions of molecules, survive failures and can be trusted.
2. [The Modern Data Stack for Chemistry](series-2/): Production tools for lab data: ingestion, warehousing, transformation and scheduling.
3. [Data Pipelines for Digital and Autonomous Chemistry](series-3/): The data side of automated synthesis: from designed molecules to checked results.
